# SD Card Photo Importer

SD Card Photo Importer 是一款 macOS 與 Windows 桌面工具，可將相機記憶卡中的照片、RAW 檔與影片安全匯入電腦。程式會先確認記憶卡配對與媒體格式，再複製檔案、驗證複製前後的內容，並記錄已匯入的檔案，避免重複匯入。

## 功能

- 支援一般照片、相機 RAW 與影片，共 53 種副檔名；首次配對時可調整允許的格式。
- 掃描相機常見的 `DCIM`、AVCHD、Sony M4ROOT／專業影片與 `CONTENTS` 資料夾。
- 同時檢查副檔名與檔案內容，阻擋格式不符或內容不像媒體檔案的項目。
- 透過簽章配對記憶卡，並檢查配對資料是否遭到修改。
- 先複製到暫存區，再以 BLAKE3 雜湊確認目的檔案與來源一致。
- 依檔案內容雜湊排除重複檔案；記錄保存在目的根目錄，方便後續掃描時略過已匯入內容。
- 以匯入日期建立資料夾，原始檔名會保留；同名但內容不同的檔案會加上雜湊識別字。
- macOS 與 Windows 可在背景監聽已配對的可移除磁碟，完成匯入後嘗試安全退出記憶卡。
- 可設定登入後自動啟動。關閉主視窗時程式會留在選單列（macOS）或系統匣（Windows）；從選單選擇「完全結束」才會停止背景監聽。

## 下載與安裝

目前 GitHub 專案提供原始碼，尚未發布可直接下載的安裝包。可從 [Releases](https://github.com/toughpeter/sd-card-reader/releases) 查看日後發布的版本；也可依下方「開發者」指令，在自己的電腦建置安裝包。

## 第一次使用

首次使用請先插入記憶卡，開啟程式並依序完成下列步驟：

1. **選擇來源**：選擇記憶卡。來源需包含相機媒體資料夾，例如 `DCIM`、AVCHD、M4ROOT 或 `CONTENTS`。
2. **驗證配對**：按「驗證配對」。尚未配對的記憶卡會顯示為未知卡。
3. **信任並初始化**：輸入卡片名稱、確認允許的照片／RAW／影片格式，再按「信任並初始化」。程式只會在記憶卡根目錄新增配對資料，不會修改或刪除照片與影片。
4. **設定匯入位置**：選擇電腦上的目的根目錄。程式會記住這個位置，供下次使用及背景自動匯入。
5. **掃描**：按「掃描照片與影片」，確認可匯入數量、容量，以及被阻擋檔案的原因。
6. **匯入**：按「開始安全匯入」，等待匯入結果。成功後程式會嘗試安全退出記憶卡；確認系統顯示已退出後再拔卡。

預設資料夾結構如下，日期是**匯入日期**：

```text
目的根目錄/
├── .sd-importer-data/       # 匯入紀錄與暫存資料
└── YYYYMMDD匯入/
    ├── IMG_0001.JPG
    └── MVI_0001.MP4
```

請勿刪除或搬移 `.sd-importer-data`，其中的匯入紀錄用來識別已匯入內容。若目的磁碟空間不足、檔案複製失敗，或記憶卡仍被其他程式占用，請依畫面訊息處理；Windows 上可先關閉正在瀏覽記憶卡的檔案總管視窗，再嘗試退出。

## 背景自動匯入

完成首次配對並選定目的根目錄後，程式會在 macOS 選單列或 Windows 系統匣背景監聽。之後插入這台電腦已配對的記憶卡，程式會自動驗證配對、匯入尚未匯入的媒體，並在成功後嘗試安全退出。

若是第一次設定、目的資料夾已移除，或背景匯入發生錯誤，請開啟主視窗查看狀態。要停止監聽，請在選單列／系統匣選擇「完全結束」。

## 格式與安全注意事項

- 格式白名單預設全選，可在首次配對或更新配對時調整。只有白名單內且檔案內容檢查通過的格式會匯入。
- 目前支援 JPEG、HEIC／HEIF、PNG、TIFF、WebP、AVIF、GIF、BMP、各品牌相機 RAW，以及 MOV、MP4、MTS、M2TS、AVI、MXF、CRM 等影片格式。
- 首次初始化會在卡片根目錄建立 `.sd-photo-importer/pairing.json` 與 `pairing.sig`。請勿手動修改或刪除，否則配對驗證會失敗。
- 配對簽章金鑰目前保存在這台電腦的應用程式資料中。移除應用程式資料、重設電腦或改用另一台電腦後，原配對可能無法驗證，需要重新初始化。
- 匯入工具不會刪除來源媒體，但仍建議先以備用卡或已備份的媒體測試。首次使用請勿只保留記憶卡上的唯一一份檔案。
- 自動退出失敗或匯入部分失敗時，程式會保留記憶卡掛載狀態；請查看匯入結果並手動處理，不要直接拔除。

## 開發者

### 環境需求

- Node.js 與 npm
- Rust 工具鏈
- Tauri 2 所需的作業系統建置依賴

### 啟動開發版

```bash
npm install
npm run tauri dev
```

只建置前端：

```bash
npm run build
```

建置桌面安裝包：

```bash
npm run tauri build
```

Rust 單元測試與 lint：

```bash
cd src-tauri
cargo test
cargo clippy --all-targets -- -D warnings
```

測試安裝步驟與驗收流程請參考 [`TESTING.md`](./TESTING.md)。
